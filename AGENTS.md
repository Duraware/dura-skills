# Working in this repository

## Branches
- Commit and push only to `dev`.
- `main` is protected: it changes only by merging a pull request from `dev` into `main`. Direct pushes, force pushes and pull requests from any other branch are blocked.

## Commits
- Author every commit as `Duraware <noreply@duraware.be>`.
